# Desafio DIO - Azure Speech Studio e Language Studio

## Descrição

Este repositório foi criado como parte do desafio da DIO, com o objetivo de praticar e aprofundar o uso das ferramentas Azure Speech Studio e Azure Language Studio.

O projeto documenta anotações, aprendizados e insights adquiridos durante a prática com soluções de inteligência artificial voltadas para fala e linguagem natural.

---

## Objetivos do Desafio

- Praticar o uso do Azure Speech Studio;
- Praticar o uso do Azure Language Studio;
- Documentar processos técnicos de forma clara;
- Utilizar o GitHub como ferramenta de documentação;
- Criar um material de apoio para estudos futuros.

---

## Ferramentas Utilizadas

- Microsoft Azure
- Azure Speech Studio
- Azure Language Studio
- GitHub
- Markdown

---

## Azure Speech Studio

O Azure Speech Studio é uma ferramenta que permite trabalhar com recursos relacionados à fala e voz.

Durante o estudo, foram observadas funcionalidades como:

- Conversão de fala em texto;
- Conversão de texto em fala;
- Reconhecimento de fala;
- Testes com áudio;
- Uso de recursos de inteligência artificial aplicados à voz.

### Aprendizados sobre Speech Studio

O Speech Studio facilita a criação de soluções que envolvem reconhecimento e síntese de voz. Ele pode ser usado em aplicações como assistentes virtuais, sistemas de atendimento, legendas automáticas e acessibilidade.

---

## Azure Language Studio

O Azure Language Studio é uma ferramenta voltada para análise e processamento de linguagem natural.

Durante o estudo, foram observadas funcionalidades como:

- Análise de sentimento;
- Extração de frases-chave;
- Detecção de idioma;
- Reconhecimento de entidades;
- Respostas a perguntas;
- Análise de textos não estruturados.

### Aprendizados sobre Language Studio

O Language Studio permite analisar textos e extrair informações importantes de forma automatizada. Ele pode ser utilizado para entender opiniões, identificar assuntos principais e criar soluções inteligentes baseadas em linguagem natural.

---

## Principais Conceitos Aprendidos

### Inteligência Artificial

A Inteligência Artificial permite que sistemas analisem dados, reconheçam padrões e auxiliem na tomada de decisões.

### Processamento de Linguagem Natural

O Processamento de Linguagem Natural, também conhecido como NLP, permite que computadores compreendam, interpretem e analisem textos escritos ou falados.

### Serviço de Fala

O serviço de Fala do Azure oferece recursos para transformar fala em texto e texto em fala.

### Análise de Texto

A análise de texto permite identificar sentimentos, idiomas, frases-chave e entidades dentro de documentos ou mensagens.

## Insights Obtidos

Durante o laboratório, percebi que os serviços de IA do Azure podem facilitar a criação de soluções inteligentes sem a necessidade de desenvolver modelos complexos do zero.

Também entendi que ferramentas como Speech Studio e Language Studio são úteis para aplicações reais, como chatbots, atendimento automatizado, análise de opiniões, acessibilidade e processamento de documentos.
